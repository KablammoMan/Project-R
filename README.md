# Project-R
Non-admin remote screen monitoring program with full keyboard and mouse control capabilities. Developed for educational and entertainment purposes only.

## Configuring the Client
To ensure that `client.py` works as intended it must be run in the same directory as a configuration script labelled `config.py` which has the following constants defined:
- `SERVER_IP` - The IP/URL of the web server to broadcast data to.
- `SERVER_PORT` - The port of the server that the application is running on (by default 8080)

## Running the server:
Simply start the server by running `npm start` or `node index.js` inside the `/Server/` directory.
